# BM25 scripted anchor v1

This system-agnostic anchor sits outside the controls pin. Every report carries
its spec and code sha256 hashes, including its import closure. Any spec or code
change is a new anchor version. It is offline, scripted, API mode only.

Documents are the pinned naive retrieval's whole-word, 240-character chunks of
events visible at `now` (`t_sim <= now`). Rank against the task prompt with
`api.adapters.bm25.BM25.scores`: k1 = 6/5, b = 3/4, fixed-point IDF and exact
rational weights. That scorer tokenizes with `\w+` over `str.casefold()`.
Keep positive scores only, top five; ties use event id, then chunk ordinal.
Join chunks with newlines, cite their event ids (including duplicates), and
return confidence 1000; no match returns naive retrieval's UNKNOWN answer.

Recall is exact quote-aware matching: every required token occurring in an
evidence event must occur together in one retrieved chunk of that event.
Events with no required tokens use event-id recall, counted separately.
Reports say `recall_basis: "chunk_quote"`. The pinned runner and reader run
unchanged. Pair points are a scripted proxy, not a bound on a live reader.
