# Validity round 1: repaired templates on fresh control-only lives

Two questions, with the needed evidence handed to the reader: do the new versions of three action templates now score as tasks that could rank a memory system, and does the count question's new answer format let a right count score? (The count question cannot rank memory yet: its answer is the same on every life, [#512](https://github.com/electricsheephq/bicentennial/issues/512).) Milestone 1's oracle row failed them ([results](../milestone-1/README.md)), a diagnostic run measured why ([#505](https://github.com/electricsheephq/bicentennial/issues/505), [#506](https://github.com/electricsheephq/bicentennial/issues/506)), and each new version changes only its prompt.

**Result (13 November 2026):** every check passed and no arm was rerun. On all four templates the no-memory row scored 0 and the oracle row 100 in each of its three trials, so `drift-chain-fault` v2, `drift-config` v2 and `drift-quote` v2 are cleared for the fresh-seed follow-up ([#394](https://github.com/electricsheephq/bicentennial/issues/394)) and `recall-count` v2's answer format is validated. Naive retrieval also scored 100 on all four: on this pack it put the needed fact in front of the reader on 34 of the 35 target items. The four are therefore labelled near-solved by naive retrieval: do-no-harm checks, excluded from any claim that memory beats retrieval.
