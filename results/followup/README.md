# The fresh-seed follow-up: Hermes native beside the controls on the four ranking kinds

Validity round 2 found four ranking candidates on one control-only pack: `drift-chain-fault` v3, `drift-config` v3, `drift-quote` v3 and `wake-loop` v1 ([round 2](../validity-2/README.md)). The follow-up runs them on 30 fresh lives in three packs of T2's shape, with the floor, the four anchors, the oracle row and Hermes native. Life by life, it reads how far the oracle row sits above each anchor (Room) and how much of that room Hermes native uses (Use) ([#394](https://github.com/electricsheephq/bicentennial/issues/394)). It is exploratory: no bar, no rank, no certification.
