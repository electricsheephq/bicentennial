# Feasibility spikes

The spikes de-risk the build before the pilot. They run at $0 on subscription lanes, under `nice`, and they never touch a production agent. The one allowed exception is S8's paid vision fallback, used only if no subscription-lane vision model exists, capped at $10 for the whole spike and reported per call. Each spike lives in its own directory with a `REPORT.md` that gives the claim, the evidence, and what the result does **not** prove.

Spikes measure mechanics, cost, timing and harness overhead. None produces a score for any memory system, and no completion-record value (PREREG-v0.4, slots C-1 to C-16) is taken from any system's score. There is no credits slot: the measured capacity of the model lane per account (slot C-11) is the only lane input to the run-time rule.

| **S1** request roles | Can the director, a model-API proxy, tell the harness's own requests apart: the main turn, compaction, summariser, extraction and title calls? | **S3** clones ([spec](s3/SPEC.md)) | One copy-on-write store clone per probe item, including parallel per-worker sandbox roots instead of serial placement | Clone time and isolation are measured, and probe throughput per hour is measured at 1, 4 and 8 workers | in progress |
| **S4** Claude Code | Can Claude Code run headless against the director, which forwards to a subscription-lane model? A subscription token is never forwarded. The swap model is also named here (completion slot C-2). | A scripted 5-turn session completes through the director, with every request classified | not started |

| **S6a** micro-life ([spec](s6a/SPEC.md)) | One 10-session micro-life on Hermes' native memory | Replay time, write-turn and summariser calls, probe latency, sustained lane concurrency (slot C-11), harness overhead (slot C-5), bundles per short life, and the run-time-rule projection are measured | in progress |
| **S6b** Sol agent lane | The S6a micro-life on a Sol subscription lane through the director. The director holds the lane's single login, and every Hermes home holds a placeholder. | Sustainable capacity per account on Sol (slot C-11 for that lane: the paced request rate where it binds), with the account count used for the projection, the shape of its rate-limit errors, write-turn and compaction latency, and the run-time-rule projection. Its numbers decide DV42, the pinned family's model lane | in progress |
| **S6** full-scale life | One full-scale life of about 200 sessions on Hermes' native memory and one extraction competitor, at K100 (uncapped) and K10 (the 10% cap). It also runs the Learn chains and measures their cost on the life's critical path. | Every cost term is measured by role, the Learn chains' cost on the life's critical path included; the run-time rule is measured at this size; and pilot bar 5's projection can be computed | not started: needs a generated life |
| **S7** write turns | Agent-curated memory works in replay. Each write-turn request equals the harness's own request plus the uniform suffix, checked by readback. | **S8** images ([spec](s8/SPEC.md)) | Can evidence that exists only in an image rendered from world state go through the director into a real harness, be asked about later by a question nobody foresaw, and separate a perception failure from a memory failure, at a known cost? Both of Hermes' image-routing modes are tested, under the observation and assistance contract. | Each measurement is reported with its sample size, and every mode × channel pair routes its image through the director with every request classified and none unknown. The Image profile leaves "pending" in Ring 0 under the spec's admission rule: fidelity first, at least 30 base questions per mode, at most 20% N/A_READER, direct evidence at least 30 points above the no-memory floor at the lower bound, and shuffled history within 10 points of it at the upper bound | not started |
| **S9** pauses | Is a pause invisible to the system? Every agent-visible surface is hashed at the pause and the resume. | A pause is invisible at $0 on public lives on Hermes native, one service-backed system and the controls, never on LCM-X; one pinned-lane session that holds compaction or encrypted reasoning state is resumed after at least 24 h on a spare account. Otherwise service-backed systems pause only between lives, and each (arm, life) keeps one account | not started |
