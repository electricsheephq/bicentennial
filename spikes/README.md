# Feasibility spikes

The spikes de-risk the build before the pilot. They run at $0 on subscription lanes, under `nice`, and they never touch a production agent. The one allowed exception is S8's paid vision fallback, used only if no subscription-lane vision model exists, capped at $10 for the whole spike and reported per call. Each spike lives in its own directory with a `REPORT.md` that gives the claim, the evidence, and what the result does **not** prove.

Spikes measure mechanics, cost, timing and harness overhead. None produces a score for any memory system, and no completion-record value (PREREG-v0.2, slots C-1 to C-15) is taken from any system's score. There is no credits slot: the measured concurrency of the model lane (slot C-11) is the only lane input to the 24-hour rule.

|---|---|---|---|
| **S1** request roles | Can the director, a model-API proxy, tell the harness's own requests apart: the main turn, compaction, summariser, extraction and title calls? It tries cursor match first, then model alias, then shape signature, and fails closed on anything unknown. | Every request in a recorded Hermes session is classified correctly, and an unknown shape is refused | not started |
| **S2** clocks ([spec](s2/SPEC.md)) | Can each harness run on simulated time? Hermes uses an in-process time shim. Claude Code uses its Node build with a preloaded `Date` shim. The fallback is director-side date rewriting with disclosure. | A 3-day simulated gap is seen consistently by the harness and its memory plug-in, with no wall-time guard tripped | in progress |
| **S3** clones ([spec](s3/SPEC.md)) | One copy-on-write store clone per probe item, including parallel per-worker sandbox roots instead of serial placement | Clone time and isolation are measured, and probe throughput per hour is measured at 1, 4 and 8 workers | in progress |
| **S4** Claude Code | Can Claude Code run headless against the director, which forwards to a subscription-lane model? A subscription token is never forwarded. The swap model is also named here (completion slot C-2). | A scripted 5-turn session completes through the director, with every request classified | not started |
| **S5** surfaces ([spec](s5/SPEC.md)) | What are the entry points of each memory system's public surface (plug-in, MCP, API), and how long do they take to run? **Extended for the capability census:** from public documentation only, which capabilities does each surveyed system document for each cell of the frozen inventory? A cell where no surveyed system documents full support is labelled "undocumented frontier", a documentation gap, not a measured frontier. | A per-system table of surfaces, write tools, state paths and adoption signals (desk survey); p50 latency follows in S5b, after installs. The census is dated, has its sources per entry, and annotates every cell of the frozen inventory; its labels never change whether a cell is scored, required or included | in progress (desk survey) |
| **S6a** micro-life ([spec](s6a/SPEC.md)) | One 10-session micro-life on Hermes' native memory | Replay time, write-turn and summariser calls, probe latency, sustained lane concurrency (slot C-11), harness overhead (slot C-5), bundles per short life, and the 24-hour-rule projection are measured | in progress |
| **S6b** Sol agent lane | The S6a micro-life on a Sol subscription lane through the director. The director holds the lane's single login, and every Hermes home holds a placeholder. | Sustained lane concurrency on Sol (slot C-11 for that lane), the shape of its rate-limit errors, write-turn and compaction latency, and the 24-hour-rule projection. Its numbers decide DV42, the pinned family's model lane | in progress |
| **S6** full-scale life | One full-scale life of about 200 sessions on Hermes' native memory and one extraction competitor, at K100 (uncapped) and K10 (the 10% cap). The life has the PREREG-v0.2 size: at least 8 long sprints, at least one per 25-session block, each at least 1.25 W, so about 1M tokens plus the sprint tokens (about 2.3M at a 128K window, about 3M at 200K). It also runs the Learn chains and measures their cost on the 24-hour critical path. | Every cost term is measured by role, the Learn chains' cost on the 24-hour critical path included; the 24-hour rule is measured at this size; and pilot bar 5's projection can be computed | not started: needs a generated life |
| **S7** write turns | Agent-curated memory works in replay. Each write-turn request equals the harness's own request plus the uniform suffix, checked by readback. A passive-pacing check is included. | The readback matches on every write turn, and the passive-pacing effect is measured on one public life | not started |
| **S8** images ([spec](s8/SPEC.md)) | Can evidence that exists only in an image rendered from world state go through the director into a real harness, be asked about later by a question nobody foresaw, and separate a perception failure from a memory failure, at a known cost? Both of Hermes' image-routing modes are tested, under the observation and assistance contract. | Each measurement is reported with its sample size, and both modes route at least one image through the director with every request classified and none unknown. The Image profile leaves "pending" in Ring 0 when both modes route, direct evidence clears the no-memory floor, and shuffled history does not | not started |
