# Standing rules: the invariant catalogue

Reconciled 17 November 2026 (UTC), at main `c3ae4a0`.

This page gives an id to each standing rule of the benchmark found so far; the list is not yet complete
([#603](https://github.com/electricsheephq/bicentennial/issues/603)). A standing rule binds every run, result or pull request
from now on; a decision that binds one run belongs in that run's declaration. Reviews, declarations and pull requests
cite rules by id. Rules V1 to V39 bind now. V40 to V51 bind the Pilot, the full tier and the board; parts of their
code exist already (V45, V48 and V51 have code and tests), and V42's freeze approval already applied to PREREG-v0.5.

Each row names where the rule is stated, the code that enforces it, the tests that prove it, and a status:
- **proved:** code enforces the rule, and a test that CI runs, and that cannot skip there, proves it;
- **partly:** code or tests cover part of the rule, or its tests run only outside CI (see [Tests outside CI](#tests-outside-ci));
- **open:** stated, with no code or test yet.

[`tests/test_invariants_doc.py`](../tests/test_invariants_doc.py) reads every line of each table under its `| ID |`
header. It checks that every row has six cells and an id `Vn`, that the ids run in order, that no table line stands
outside a table, and that every status is one of the three. Each *Proved by* cell must be `none` or one or more full
test ids `path.py::test_name`, each in its own backticks, separated by `; `, and each test so named must be a
top-level test in that file. Every proved row must name at least one test that CI collects (a `test_*.py` or
`*_test.py` file under `tests/`) and that cannot skip there: no skip, skipif or xfail mark, no `pytest.skip` or
`importorskip` call, and no module-level `pytestmark` or skip. An async test counts as unable to run, since no async
test plugin is installed. This part of the check is static: it reads only the named test's own body and decorators
and its module's top-level statements. It does not see a skip reached through a helper function, a skip function imported under another name,
`unittest.SkipTest`, a `__test__ = False` opt-out, a fixture or a conftest hook, so review still checks each proof.

## Tests outside CI

CI collects `tests/` only (`testpaths` in `pyproject.toml`), in files named `test_*.py` or `*_test.py` (pytest's defaults). The tests beside a run's code
(`results/followup/run/test_*.py`, `results/validity-1/v2-control-trials/test_table.py`,
`results/validity-2/control-trials/test_table.py`, `results/milestone-1/2026-11-11-separation-table/test_table.py`)
run in that run's rehearsal (the follow-up's) or by hand, so a row that rests on them is partly proved until CI runs
them.
